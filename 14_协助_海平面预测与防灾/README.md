## 一、项目概述

本项目是为他人（同学/朋友）提供可视化技术支持，主题围绕海平面上升预测和沿海城市防灾规划。制作了5类专业可视化图表。

### 可视化产出

| 图表 | 内容 | 方法 |
|------|------|------|
| 海平面预测与入侵概率热力图 | 1990-2075年海平面趋势 + 沿海城市概率矩阵 | matplotlib + seaborn热力图 |
| 短长期损失评估对比图 | 10城市×短期(10年)vs长期(50年)经济损失 | 分组柱状图 |
| 综合风险分级热力图 | 15城市×5风险因子的风险矩阵 | 自定义颜色映射热力图 |
| 防波堤成本-效益分析 | 堤高vs成本/风险降低率的双Y轴图 | twinx双轴图 |
| 功能区搬迁优化对比 | 5类功能区优化前后风险对比 | 分组柱状图 |

## 二、技术方法

### 可视化技术栈
- Python matplotlib + seaborn
- 中文显示配置（SimHei字体）
- 自定义颜色映射(LinearSegmentedColormap)
- 双Y轴图表（twinx）

### 模拟数据策略
由于缺乏真实数据，所有数据基于合理的假设和模拟生成：
- 海平面上升趋势（线性 + 周期性波动 + 噪声）
- 入侵概率（均匀分布模拟）
- 经济损失（短期×放大系数→长期）

## 三、技术总结

### 3.1 数据可视化的设计原则

1. **信息密度适中**：每张图只传达一个核心信息
2. **标注清晰**：关键数值（如2075年预测值）加标注线
3. **色盲友好**：使用不需要颜色辨别的辅助标记（标注数值）
4. **比例合理**：双Y轴时注意尺度不产生误导

### 3.2 海平面上升的科学背景

1. **趋势**：全球平均海平面以约3.7mm/年的速度上升（1993-2023卫星数据）
2. **机制**：热膨胀（50%）+ 冰川融化（42%）+ 冰盖消融（8%）
3. **区域差异**：受地壳垂直运动、洋流变化影响，不同沿海城市面临的风险不同
4. **临界点**：格陵兰冰盖和西南极冰盖的不可逆融化是气候系统的主要临界点(Tipping Point)

### 3.3 气候适应 vs 气候减缓

1. **减缓(Mitigation)**：减少碳排放，从根源上控制升温
2. **适应(Adaptation)**：建防波堤、功能区搬迁、提升基础设施标准
3. **本题属于"适应"范畴**：即使全球即刻碳中和，已排放的碳仍将导致数十年海平面上升
4. **发展中国家的困境**：最需要适应的往往是资金和技术能力最弱的国家（如孟加拉国、马尔代夫）

### 3.4 反思

虽然是协助项目，但帮助他人可视化也是学习的过程。数据可视化不仅是"画好看的图"，更是用视觉语言讲故事——一张好的图可以胜过千言万语。在海平面上升这类"慢暴力"(Slow Violence)问题中，可视化是唤起公众意识的有力工具。
