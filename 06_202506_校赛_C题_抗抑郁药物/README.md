## 一、题目概述

### 1.1 问题背景

全球抑郁症患者超3.5亿，中国超9500万。某制药公司开展抗抑郁药物临床试验，需评估药物A、B（试验组）与药物C（对照组）的疗效和安全性。数据包含1575例受试者、4个随访时点（1/3/6/12月）的8类主诉症状。

### 1.2 四个问题

| 问题 | 内容 |
|------|------|
| 1 | 基线特征均衡性检验（验证随机化效果） |
| 2 | 影响因素分析（婚姻、用药史、抑郁程度→疗效/副作用） |
| 3 | 长期疗效动态评估（症状轨迹、缓解率、复发率） |
| 4 | 个体化用药建议（分层决策框架） |

---

## 二、建模方法全景

### 问题1：统计推断
- **ANOVA**：年龄组间比较
- **卡方检验**：分类变量（婚姻、用药史、抑郁程度）均衡性
- **Shapiro-Wilk + Levene**：正态性和方差齐性验证

### 问题2：分层逻辑回归
- 对每种药物分别建立逻辑回归
- **核心发现**：初始抑郁程度是最强预测因子
  - 中度抑郁 OR=1.89-2.12
  - 重度抑郁 OR=2.58-3.05
- 药物C组：丧偶患者风险显著增加(OR=1.85)

### 问题3：动态评估
- **线性混合效应模型(LMM)**：刻画症状改善轨迹
  $$S_{ij} = \beta_0 + \beta_1 Time + \beta_2 Group + \beta_3 Time \times Group + u_i + \epsilon_{ij}$$
- **Kaplan-Meier生存分析 + Cox回归**：复发风险评估
  - 药物A: 无复发生存率91.8%（最优）
  - 药物B: 89.5%
  - 药物C: 85.0%

### 问题4：个性化推荐
- **随机森林分类**：预测最优药物（10折CV准确率81.2%）
- **TOPSIS多准则决策**：平衡缓解率/复发率/副作用
- **决策树可视化**：基于抑郁程度和用药史的分层推荐规则

## 三、关键结果

| 疗效指标 | 药物C（对照组） | 药物A | 药物B |
|---------|:---:|:---:|:---:|
| 12月缓解率 | 78.2% | 82.5% | **85.3%** |
| 6-12月复发率 | 15.0% | **8.2%** | 10.5% |
| TOPSIS贴近度 | 0.42 | 0.65 | **0.73** |

**推荐策略**:
- 轻度抑郁 → 药物C（安全优先）
- 中度+有用药史 → 药物A（快速控制）
- 中度+无用药史 → 药物B（温和起效）
- 重度+年轻 → 药物B（深度缓解）

## 四、技术总结与思考

### 4.1 临床统计学方法

1. **逻辑回归是医学研究的标配**：OR（优势比）直观解释了风险因素效应，临床医生容易理解
2. **混合效应模型**处理重复测量数据的优势：区分个体间变异(u_i)和个体内相关性
3. **生存分析不仅是"死亡"**：复发、停药、不良事件都是"事件"，Cox回归捕获了时间维度的风险

### 4.2 精神卫生社会思考

1. **抗抑郁药的"黑箱"**：我们至今不完全理解SSRI类药物的精确机制——5-羟色胺假说只是一种可能解释
2. **中国精神卫生资源严重不足**：精神科医生仅约4万名（每10万人2.2名），远低于发达国家的10-15名
3. **病耻感(Stigma)**：许多抑郁症患者不愿就医，"扛一扛就过去了"——这导致大量患者首次就诊时已是中重度
4. **药物≠全部**：心理治疗（CBT、IPT）与药物治疗联合的效果优于单独用药，但心理治疗的可及性更低

### 4.3 个体化医疗的未来

1. **药物基因组学**：CYP450酶（特别是CYP2D6和CYP2C19）的基因多态性影响抗抑郁药代谢——未来可能先测基因再开药
2. **数字表型(Digital Phenotyping)**：手机使用模式、语音特征可能成为抑郁症的客观标志物
3. **AI辅助诊断**：基于电子健康记录的机器学习模型可预测治疗应答，减少试错

### 4.4 比赛反思

本题的最大收获是统计方法的系统性应用——从描述性统计到推断性统计，从回归到生存分析，形成了完整的生物统计方法论链条。不足之处在于：
- 数据为模拟数据，与现实临床试验数据的复杂性（如非随机缺失、方案违背）有差距
- 模型的可解释性优于黑箱模型的预测精度，这在医学背景下是正确的导向
