## 模型实现细节

### 问题1：无噪声时间对齐

**方法**: 
1. 对方式1数据建立三次样条插值作为连续参考轨迹
2. 定义代价函数 J(δ) = Σ||p1_ref(t2-δ) - p2||²
3. 粗搜索：在δ的整个可行范围 [t2[0]-t1[-1], t2[-1]-t1[0]] 内等间距搜索
4. 精优化：在粗估计±30s范围内使用bounded标量优化

**结果**:
- 时间偏差 δ = 198.4317 s
- RMSE = 3.22×10⁻⁸ m（≈0，验证了无噪声假设）
- 重叠点: 3502个（共4001个方式2点中的87.5%）
- 10Hz轨迹: 7004个点，覆盖[270.40, 970.70]s

**分析**: δ=198.43s表示方式2比方式1晚开机约198秒。RMSE≈0证实了无噪声假设，也验证了模型正确性。

### 问题2：含噪声+系统偏差的联合估计

**方法**:
1. 对方式1数据做Savitzky-Golay滤波（窗口21，3阶）降低噪声对插值的影响
2. 粗搜索：使用MSE代价函数（除以重叠点数），并内置均值偏移鲁棒处理
3. 交替优化：
   - 固定偏差b，一维优化时间偏移δ
   - 固定δ，解析求解b = mean(p2 - p1_ref)
   - 迭代至收敛

**结果**:
- 时间偏差 δ = 50.4621 s
- 系统偏差 b = (3.4748, -1.8336) m
- RMSE = 1.2346 m（校正后残差，反映噪声水平）
- 重叠点: 3450个
- 10Hz轨迹: 6900个点

**分析**: 系统偏差约3.5m和-1.8m，说明方式2存在固定的二维平移误差。RMSE 1.23m为随机噪声的影响，校正后轨迹质量显著提升。

### 问题3：实际数据偏差异常检测与融合

**方法**:
1. 先假设无系统偏差，估计时间偏移 δ₀
2. 在重叠时间点计算两种方式的位差 dx, dy
3. 对dx, dy分别做单样本t检验（H₀: 均值为0）
4. 若p<0.01则判定存在系统偏差
5. 无论检测结果如何，均进行联合估计以获取最优参数

**结果**:
- 步骤1: δ₀ = -367.93s, 重叠1501点
- 步骤2:
  - mean(dx) = 0.124m, p_x = 0.138 → 不显著
  - mean(dy) = 0.172m, p_y = 0.037 → 不显著（>0.01）
  - **结论: 无显著系统偏差**
- 步骤3:
  - δ = -367.92s（与步骤1几乎一致，验证了无偏差假设）
  - b = (-0.127, -0.172)m（偏差量极小，<0.2m）
  - RMSE = 4.5289m
  - 10Hz轨迹: 3001个点

**分析**: t检验无法拒绝零假设（p>0.01），结合联合估计所得偏差极小（<0.2m），判定该实际数据中不存在显著的系统偏差。RMSE=4.53m相对较高，可能是实际测量中噪声水平较高或存在非平移系统误差导致。

### 问题4：任务调度优化

**约束参数设置**（基于轨迹统计特征自适应确定）:

| 参数 | 射击任务 | 拍照任务 |
|------|---------|---------|
| 距离范围 | [3, 55] m | [2, 55] m |
| 最大线速度 | ≤30.0 m/s (p50) | ≤20.0 m/s (p35) |
| 最大加速度 | ≤275.6 m/s² (p60) | ≤226.6 m/s² (p50) |
| 准备时间 | 1.5s | 0.5s |
| 角度约束 | - | 不同拍摄角≥30° |

**窗口提取**:
1. 对每个目标，遍历10Hz轨迹点，标记满足距离+速度+加速度约束的点
2. 连续满足约束的点形成一个候选窗口
3. 窗口需包含准备时间（射击1.5s、拍照0.5s期间的每个点也都满足约束）
4. 拍照任务按目标分组，贪心选择角度差异≥30°的窗口

**区间调度优化**:
1. 每个候选窗口 = (开始准备时刻, 结束时刻, 权重1.0)
2. 按结束时间排序
3. 动态规划求解加权区间调度问题:
   - dp[j] = max(dp[j-1], profit_j + dp[p(j)+1])
   - p(j): 不冲突的前驱任务索引
4. 回溯得到最优任务序列

**结果**:

- 最优调度: **13个任务** (4个射击 + 9个拍照)

## 模型评价

### 优点
1. 时间对齐模型通过粗+精两级搜索，保证全局最优性
2. 联合估计交替优化收敛稳定，同时求解时间和空间偏差
3. 使用MSE而非SSE作为代价函数，避免小重叠的局部最优
4. 自适应约束阈值使任务调度贴合实际数据特征
5. 动态规划算法保证区间调度的全局最优解

### 不足与改进方向
1. 系统偏差仅考虑二维平移，未考虑旋转或尺度因子
2. 10Hz轨迹使用样条插值，大噪声时可能产生局部振荡
3. 约束参数基于数据统计，缺乏物理先验
4. 未考虑任务失败概率和动态重规划
