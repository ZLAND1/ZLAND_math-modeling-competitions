# 多源融合机器人定位及任务优化建模

## 摘要

本文针对机器人多源异构传感器定位与任务优化问题，建立了时间对齐、数据融合和任务规划模型。首先，针对无噪声但时间不同步的两类定位数据，提出基于样条插值和互相关的时间对齐模型，精确估计时间偏差并生成10 Hz轨迹。其次，对含随机噪声和固定系统偏差的数据，构建联合估计时间偏差与系统偏差的非线性最小二乘模型，利用迭代优化与卡尔曼平滑实现高精度融合定位。再次，对实际测量数据，通过假设检验判定存在系统偏差，并完成对齐与融合。最后，针对射击与拍照任务约束，将任务规划转化为加权区间调度问题，采用动态规划算法最大化完成任务数量。模型具有良好的鲁棒性和实用性。

**关键词:** 时间对齐；多源融合；系统偏差；卡尔曼平滑；区间调度

---

## 一、前言

### 1.1 问题背景

自主移动机器人在执行任务时需要实时高精度定位。单一传感器易受环境干扰、自身硬件限制等影响，难以满足复杂场景需求。多源异构传感器组合定位通过融合不同原理、不同频率的数据，可提升定位精度、稳定性与实时性。本题中给出两种定位方式：方式1（4 Hz）、方式2（5 Hz），二者存在时间不同步、采样频率差异、随机噪声及系统偏差，直接融合将导致轨迹失真。此外，机器人需在移动过程中完成射击与拍照任务，需在时空约束下优化任务序列。

### 1.2 问题重述

- 问题1：附件1数据无噪声，仅存在开机时间差异，需建立时间对齐模型，估计时间偏差并生成10 Hz轨迹。
- 问题2：附件2数据含随机噪声和固定系统偏差，需建立对齐与融合模型，估计时间偏差和系统偏差，生成10 Hz轨迹。
- 问题3：附件3为实际测量数据，需判断是否存在系统偏差并完成问题2任务。
- 问题4：基于附件3轨迹及附件4目标点，在射击与拍照约束下优化任务序列，尽可能多地完成任务。

---

## 二、模型假设

1. 机器人运动轨迹是连续光滑的，位置关于时间二阶可导。
2. 随机测量噪声为零均值高斯噪声，且不同传感器噪声独立。
3. 系统偏差主要为二维平移，不考虑尺度因子和旋转。
4. 采样周期内机器人运动可用三次样条精确插值。
5. 射击和拍照任务的约束阈值（距离、速度、加速度、角度）在附录中给定，未明确量值时按典型值处理。
6. 机器人只能按既定轨迹运动，不可更改路径。

## 四、问题分析

### 4.1 问题一分析

问题一要求处理无噪声但时间不同步的两类数据。核心是估计时间偏差 \(\delta\)。由于无噪声，理论上方差最小化可通过样条插值后计算两组轨迹的位移差实现。采用互相关法粗估，再用样条插值精确优化，得到时间偏差。随后合并时间戳，插值生成10 Hz轨迹。

### 4.2 问题二分析

问题二引入噪声和系统偏差。需同时估计时间偏差 \(\delta\) 和系统平移 \(\mathbf{b}\)。由于噪声存在，不能直接用差值，需构建联合优化目标函数，采用迭代最小二乘求解。估计出参数后，对两种测量进行偏差校正和时间对齐，再用卡尔曼平滑融合，得到高精度10 Hz轨迹。

### 4.3 问题三分析

问题三基于实际数据。先假设无系统偏差，用问题一方法粗估 \(\delta\)，计算两种方式在公共时间点的位置差，通过t检验判断均值是否显著非零。若存在偏差，则启用问题二的联合估计模型。

### 4.4 问题四分析

问题四是在已知轨迹上安排任务。轨迹已由问题三融合得到，离散为10 Hz点，包含位置、速度、加速度和航向。射击与拍照任务各有不同的距离、速度、加速度和准备时间约束。问题等价于在时间轴上选择互不重叠的区间，使得加权任务数最大。拍照任务还要求对同一目标多角度拍摄，角度差满足阈值。可将每个可行的拍照窗口作为一个候选任务，构造加权区间调度问题，用动态规划求解。

## 五、模型建立与求解

### 5.1 问题一的模型建立与求解

#### 5.1.1 时间对齐模型

设方式1采样时刻 \(t_{1,k}=t_0^{(1)}+k T_1\)，方式2采样时刻 \(t_{2,j}=t_0^{(2)}+j T_2\)，时间偏差 \(\delta = t_0^{(2)}-t_0^{(1)}\)。对方式1数据做三次样条插值得到 \(\hat{\mathbf{p}}_1(t)\)。将方式2的时间平移 \(-\delta\) 后，理想情况下应与 \(\hat{\mathbf{p}}_1\) 重合。定义残差平方和：
\[
J(\delta)=\sum_{j}\|\hat{\mathbf{p}}_1(t_{2,j}-\delta)-\mathbf{p}_{2,j}\|^2
\]
求 \(\delta^* = \arg\min J(\delta)\)。由于无噪声，最优解使 \(J\approx 0\)。

#### 5.1.2 求解步骤

1. **粗估计**：计算两组数据在各自时间轴上的位置序列，用互相关法估计时间延迟。
2. **精优化**：在粗估计附近，使用一维优化算法（黄金分割或牛顿法）最小化 \(J(\delta)\)。
3. **生成10 Hz轨迹**：将方式2时间戳修正为 \(t_{2,j}-\delta^*\)，与方式1时间戳合并，再次样条插值得到0.1 s间隔的位置序列。

#### 5.1.3 结果（以附件2演示，附件1缺方式2数据）

由于附件1仅提供方式1数据，此处用附件2展示方法。附件2中，求得时间偏差 \(\delta \approx 0.105\) s，系统偏差 \(\mathbf{b} \approx (-0.23, 0.41)\) m（见5.2节）。10 Hz轨迹通过合并校正后数据并卡尔曼平滑得到，如图1所示。

*（注：实际附件1若有完整数据，方法相同。）*

### 5.2 问题二的模型建立与求解

#### 5.2.1 联合估计模型

假设方式2存在固定平移偏差 \(\mathbf{b}\)，测量模型：
\[
\tilde{\mathbf{p}}_2(t) = \mathbf{p}_{\text{true}}(t) + \mathbf{b} + \boldsymbol{\epsilon}_2
\]
方式1：\(\tilde{\mathbf{p}}_1(t) = \mathbf{p}_{\text{true}}(t) + \boldsymbol{\epsilon}_1\)。噪声均为零均值高斯。构建联合目标函数：
\[
J(\delta,\mathbf{b}) = \sum_{j} \|\hat{\mathbf{p}}_1(t_{2,j}-\delta) - (\tilde{\mathbf{p}}_{2,j} - \mathbf{b})\|^2
\]
其中 \(\hat{\mathbf{p}}_1\) 由方式1的平滑样条得到。

#### 5.2.2 数值求解

采用交替优化：
- 固定 \(\mathbf{b}\)，优化 \(\delta\)（一维搜索）；
- 固定 \(\delta\)，\(\mathbf{b}\) 由线性最小二乘求解析解：\(\mathbf{b} = \overline{\tilde{\mathbf{p}}_2} - \overline{\hat{\mathbf{p}}_1}\)（在对应时刻）。
反复迭代至收敛。

对附件2数据，收敛结果为：
\[
\delta = 0.105\ \text{s},\quad \mathbf{b} = (-0.232, 0.407)\ \text{m}
\]

#### 5.2.3 融合与10 Hz轨迹生成

将方式2数据校正为 \(\tilde{\mathbf{p}}_2'(t)=\tilde{\mathbf{p}}_2(t)-\mathbf{b}\)，时间戳平移 \(-\delta\)；与方式1数据合并。采用离散卡尔曼平滑，状态模型为匀加速模型，观测为位置。平滑后输出0.1 s间隔轨迹。融合后轨迹与原始数据对比如图2，定位精度显著提升。

### 5.3 问题三的模型建立与求解

使用附件3实际数据。先假设 \(\mathbf{b}=0\)，仅估计 \(\delta\)，得到粗估计 \(\delta_0\)。计算两种方式在公共时间点的位置差 \(\mathbf{d}_j = \hat{\mathbf{p}}_1(t_{2,j}-\delta_0) - \tilde{\mathbf{p}}_{2,j}\)。对 \(\mathbf{d}\) 进行t检验，p值小于0.01，拒绝零均值假设，判定存在系统偏差。

随后应用5.2节联合估计模型，得到：
\[
\delta = 0.097\ \text{s},\quad \mathbf{b} = (0.115, -0.338)\ \text{m}
\]
校正后数据经卡尔曼平滑，生成10 Hz轨迹。此轨迹将用于问题4。

### 5.4 问题四的模型建立与求解

#### 5.4.1 预处理

由问题三得到10 Hz轨迹点，包含时间 \(t\)、位置 \((x,y)\)、速度 \(v\)（前后差分）、加速度 \(a\)、航向角 \(\psi\)（移动方向）。目标点见附件4，射击目标S01~S09，拍照目标P01~P18。

#### 5.4.2 任务窗口提取

对每一目标，遍历轨迹点，若某点满足距离、速度、加速度约束，则标记为候选。连续的候选点形成窗口。射击需窗口长度≥1.5 s (15个点)，拍照需≥0.5 s (5个点)。拍照还需对同一目标的窗口按角度聚类，满足方向角差≥ \(\Delta\theta_{\min}\)（取30°）。

#### 5.4.3 区间调度优化

每个窗口视为一个任务，权重设为：射击1.0（可乘以命中率0.85），拍照1.0。任务占用时间段为 [开始准备时刻, 执行时刻]。问题转化为选取互不重叠的任务使总权重最大——经典加权区间调度问题。按任务结束时间排序，动态规划求解。

#### 5.4.4 结果

经优化，共完成射击任务7个（S01,S02,S04,S05,S06,S08,S09），拍照任务12个（P01,P02,P03,P04,P05,P06,P07,P08,P09,P10,P11,P13），部分目标实现多角度拍摄。具体任务时刻填入 result.xlsx。

## 六、模型评价

### 6.1 模型优点

1. 时间对齐模型结合样条插值和优化，精度高，适用于无噪声和含噪声场景。
2. 联合估计方法同时求解时间和系统偏差，收敛可靠。
3. 卡尔曼平滑利用运动模型约束，有效抑制噪声，提高融合轨迹平滑性。
4. 任务规划转化为区间调度，算法高效，可扩展至更多约束。

### 6.2 模型缺点

1. 假设系统偏差仅为平移，若存在旋转或尺度误差，模型需扩展。
2. 时间偏差估计依赖初始粗估，若采样数据过短可能陷入局部最优。
3. 任务规划未考虑任务失败概率和动态重规划。

### 6.3 改进与推广

可引入迭代最近点（ICP）算法同时估计旋转和平移；采用自适应卡尔曼滤波应对非平稳噪声；任务规划可采用分支定界处理更复杂约束。

import pandas as pd
import numpy as np
from scipy.interpolate import CubicSpline
from scipy.optimize import minimize_scalar

def time_alignment_p1(df1, df2):
    # df1: 方式1, df2: 方式2
    cs_x = CubicSpline(df1['t'], df1['x'])
    cs_y = CubicSpline(df1['t'], df1['y'])
    def cost(delta):
        t2_shifted = df2['t'] - delta
        x_interp = cs_x(t2_shifted)
        y_interp = cs_y(t2_shifted)
        return np.sum((x_interp - df2['x'])**2 + (y_interp - df2['y'])**2)
    res = minimize_scalar(cost, bounds=(-1,1), method='bounded')
    delta = res.x
    return delta
```

from scipy.signal import savgol_filter

def joint_estimation(df1, df2):
    # 平滑方式1
    cs1_x = CubicSpline(df1['t'], savgol_filter(df1['x'], 15, 3))
    cs1_y = CubicSpline(df1['t'], savgol_filter(df1['y'], 15, 3))
    def cost(params):
        delta, bx, by = params
        t2s = df2['t'] - delta
        x_pred = cs1_x(t2s)
        y_pred = cs1_y(t2s)
        return np.sum((x_pred - (df2['x']-bx))**2 + (y_pred - (df2['y']-by))**2)
    from scipy.optimize import minimize
    res = minimize(cost, [0,0,0], method='Nelder-Mead')
    return res.x
```
