# 多源融合机器人定位及任务优化 —— 完整建模思路

## 摘要

本文针对机器人多源异构传感器定位与任务优化问题，建立了时间对齐、联合估计与任务规划模型。**问题1**针对无噪声但时间不同步的两类定位数据，提出基于三次样条插值的残差最小化时间对齐模型，通过粗-精两级搜索精确估计时间偏差δ=198.43s，RMSE≈0。**问题2**面向含随机噪声和固定系统偏差的数据，构建交替优化的联合估计模型，同时求解时间偏差δ=50.46s和系统平移b=(3.47,-1.83)m，校正后RMSE=1.23m。**问题3**对实际测量数据，通过t检验判定无显著系统偏差（p>0.01），并完成高精度融合，RMSE=4.53m。**问题4**将任务规划转化为加权区间调度问题，基于自适应约束阈值提取候选窗口，采用动态规划算法求解，最终完成13个任务（4射击+9拍照），部分目标实现多角度拍摄。

**关键词:** 时间对齐；多源融合；系统偏差估计；样条插值；区间调度；动态规划

---

## 一、问题重述与分析

### 1.1 问题背景

自主移动机器人依靠多源异构传感器实现高精度定位。本题中两类定位方式（方式1: 4Hz，方式2: 5Hz）存在时间不同步、采样频率差异、随机噪声及可能存在的系统偏差。此外，机器人需在运动中完成射击与拍照任务。

### 1.2 四个子问题

| 问题 | 数据类型 | 核心任务 | 输出 |
|------|---------|---------|------|
| 问题1 | 无噪声（附件1） | 估计时间偏差δ，生成10Hz轨迹 | δ, 10Hz轨迹 |
| 问题2 | 含噪声+系统偏差（附件2） | 联合估计δ和系统偏差b，融合生成10Hz轨迹 | δ, b, 10Hz轨迹 |
| 问题3 | 实际测量（附件3） | 检测系统偏差，完成问题2任务 | 偏差异常检测结论, δ, b, 10Hz轨迹 |
| 问题4 | 问题3轨迹+目标点（附件4） | 约束下优化任务序列 | 任务调度表(result.xlsx) |

---

## 二、模型假设

1. 机器人轨迹连续光滑，位置关于时间二阶可导
2. 随机测量噪声服从零均值高斯分布，传感器间噪声独立
3. 系统偏差主要为二维平移，不考虑旋转和尺度因子
4. 采样周期内机器人运动可由三次样条精确插值
5. 机器人不可更改既定轨迹，只能按轨迹运动

## 四、模型建立与求解

### 4.1 问题1：无噪声时间对齐

#### 4.1.1 数学模型

设方式1采样时刻 t₁,ₖ = t₀⁽¹⁾ + kT₁，方式2采样时刻 t₂,ⱼ = t₀⁽²⁾ + jT₂。对方式1数据做三次样条插值得 p̂₁(t) = (x̂₁(t), ŷ₁(t))。

定义残差平方和代价函数：

$$J(δ) = \sum_j \|\hat{p}_1(t_{2,j} - δ) - p_{2,j}\|^2$$

最优时间偏差: δ* = argmin J(δ)

#### 4.1.2 求解策略

**粗搜索**: δ的可行范围为 [t₂[0]-t₁[-1], t₂[-1]-t₁[0]]，在此范围内等间距采样300点，选取J(δ)最小者为粗估计值。

**精优化**: 以粗估计为中心±30s，使用bounded标量优化精确求解。

#### 4.1.3 结果

| 参数 | 数值 |
|------|------|
| δ | 198.4317 s |
| RMSE | 3.22×10⁻⁸ m |
| 重叠点数 | 3502 / 4001 (87.5%) |

RMSE ≈ 0 验证了无噪声假设和模型正确性。

#### 4.1.4 10Hz轨迹生成

将方式2时间戳校正为 t₂ - δ后与方式1合并，三次样条插值到0.1s间隔。共生成7004个点，覆盖[270.40, 970.70]s。

### 4.2 问题2：含噪声+系统偏差联合估计

#### 4.2.1 数学模型

方式2的测量模型：
$$\tilde{p}_2(t) = p_{true}(t) + b + ε_2$$

方式1: p̃₁(t) = p_true(t) + ε₁

联合代价函数：
$$J(δ, b) = \sum_j \|\hat{p}_1(t_{2,j} - δ) - (\tilde{p}_{2,j} - b)\|^2$$

其中 p̂₁ 由Savitzky-Golay滤波后的方式1数据通过三次样条构建。

#### 4.2.2 数值求解：交替优化

**算法流程**:
1. 初始化: δ⁽⁰⁾ = δ_coarse, b⁽⁰⁾ = (0, 0)
2. 重复以下步骤至收敛:
   - **固定b，优化δ**: 一维bounded标量优化
   - **固定δ，求解b**: bₓ = mean(p̃₂,ₓ - x̂₁), bᵧ = mean(p̃₂,ᵧ - ŷ₁)
3. 收敛条件: |Δb| < 10⁻⁸

其中粗搜索δ_coarse使用MSE代价函数（内置均值偏移鲁棒处理），避免SSE偏好的小重叠局部最优。

#### 4.2.3 结果

| 参数 | 数值 |
|------|------|
| δ | 50.4621 s |
| b | (3.4748, -1.8336) m |
| RMSE (校正后) | 1.2346 m |
| 重叠点数 | 3450 |

系统偏差约3.5m和-1.8m，说明方式2存在固定平移误差。校正后RMSE=1.23m反映随机噪声水平。

#### 4.2.4 融合与10Hz轨迹

校正方式2（减偏差+移时间）后与方式1合并，平滑样条插值生成10Hz轨迹(6900点)。

### 4.3 问题3：实际数据偏差异常检测与处理

#### 4.3.1 偏差异常检测

**步骤1**: 假设无系统偏差，估计时间偏移δ₀ = -367.93s（重叠1501点）

**步骤2**: 在重叠时间点计算位差并做t检验:

$$H_0: μ_{dx} = 0, \quad H_0: μ_{dy} = 0$$

| 方向 | 均值 | t统计量 | p值 | 结论(α=0.01) |
|------|------|---------|-----|--------------|
| X | 0.124m | 1.48 | 0.138 | 不拒绝H₀ |
| Y | 0.172m | 2.09 | 0.037 | 不拒绝H₀ |

**结论**: 在α=0.01水平下，无显著证据表明存在系统偏差。

#### 4.3.2 联合估计（问题3）

尽管t检验未检测到显著偏差，仍进行完整的联合估计以获得最优参数：

| 参数 | 数值 |
|------|------|
| δ | -367.9200 s |
| b | (-0.1273, -0.1723) m |
| RMSE | 4.5289 m |
| 重叠点数 | 1500 |

偏差量极小（<0.2m），与t检验结论一致。RMSE=4.53m相对较高，说明实际测量噪声水平较高。

**分析**: δ = -368s表示方式2的时钟比方式1慢约368秒（方式2时间读数+368s → 方式1时间读数），使得两个时间序列的轨迹段对齐。

#### 4.3.3 10Hz融合轨迹

合并校正后数据，使用平滑样条（s_factor=0.3）生成含3001个点的10Hz轨迹，覆盖[469.05, 769.05]s。

### 4.4 问题4：任务调度优化

#### 4.4.1 轨迹状态提取

由问题3的10Hz轨迹计算每个时间点的:
- 线速度 v = √(vₓ² + vᵧ²)（梯度法）
- 加速度 a = √(aₓ² + aᵧ²)
- 航向角 ψ = atan2(vᵧ, vₓ)

#### 4.4.2 约束参数

基于轨迹统计数据自适应确定约束阈值：

| 参数 | 射击任务 | 拍照任务 |
|------|---------|---------|
| 距离 | [3, 55] m | [2, 55] m |
| 线速度 | ≤30 m/s (p50) | ≤20 m/s (p35) |
| 加速度 | ≤276 m/s² (p60) | ≤227 m/s² (p50) |
| 准备时间 | 1.5 s | 0.5 s |
| 角度要求 | — | 同目标不同角度≥30° |

#### 4.4.3 候选窗口提取

对每个目标，遍历所有10Hz轨迹点，满足距离∩速度∩加速度约束的点标记为"可行"。连续可行点且包含完整准备期（射击前1.5s/拍照前0.5s内所有点均可行）的形成一个候选窗口。

拍照任务按目标分组，按开始时间贪心选择角度差异≥30°的窗口。

#### 4.4.4 加权区间调度（动态规划）

每个候选窗口 = (开始准备时刻, 结束时刻, 权重=1.0)

**DP递推**:
$$dp[j] = \max(dp[j-1], w_j + dp[p(j)+1])$$

其中 p(j) = 最后一个不与任务j冲突的任务索引（二分查找）。

## 五、模型总结

### 5.1 模型优点

1. **两级搜索策略**（粗+精）保证时间偏差的全局最优
2. **MSE代价函数**解决SSE偏向小重叠的局部最优问题
3. **交替优化**框架稳定收敛，同时求解多参数
4. **自适应约束**阈值基于数据统计，可推广至不同数据集
5. **动态规划**保证区间调度的最优性，高效（O(n log n)）

### 5.2 模型不足与改进

1. 系统偏差仅考虑平移，可扩展ICP算法处理旋转
2. 样条插值在噪声大时可能振荡，可改用卡尔曼平滑
3. 任务规划未考虑失败概率和重规划
4. 约束参数缺乏物理意义，可结合具体平台标定

### 5.3 推广方向

- **自适应卡尔曼滤波**: 在线估计噪声协方差
- **分支定界**: 处理更复杂的任务约束
- **蒙特卡洛模拟**: 考虑命中率的不确定性
