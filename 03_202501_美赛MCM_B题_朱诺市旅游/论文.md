# 朱诺市旅游可持续管理：多目标协同优化模型

> 2025年MCM/ICM Problem B | 论文编号：2510451  
> Managing Sustainable Tourism in Juneau, Alaska

---

## 摘要

阿拉斯加朱诺市旅游业面临三重挑战：经济上对邮轮收入过度依赖（占比74%）；环境上年碳排放28,000吨，冰川退缩速率6.2米/年；社会层面居民满意度仅3.8/5分。本研究构建多目标协同优化模型，系统整合经济收益、环境承载力和社区满意度三个子系统。通过系统动力学模拟求解，提出旺季邮轮税20%浮动策略、热门景点单日限流2,000人、生态修复支出占比提升至40%等具体措施。长期模拟表明：邮轮与独立游客量分别控制在日均3,000人与1,200人，年财政收入增长至4,160万美元，碳排放降低10.6%，居民满意度提升至4.2分。

**关键词**：多目标规划；旅游可持续发展；系统动力学；环境承载力；社区满意度

---

## 一、问题背景

朱诺市每年接待超160万邮轮游客，旅游收入是城市经济支柱，但带来：
- **环境压力**：碳排放、冰川退化、海洋垃圾
- **社会矛盾**：住房成本攀升、游客密度过大、居民生活质量下降
- **经济脆弱性**：季节性波动、过度依赖邮轮公司

---

## 二、模型构建

### 2.1 多目标协同优化框架

**三个子系统**：

**① 经济收益子系统**：
$$\max R = R_{direct} + R_{indirect} - C_{explicit} - C_{hidden}$$

- 直接收入：邮轮税、游客税、停泊费
- 间接收入：游客消费（交通、纪念品、餐饮）
- 显性支出：港口维护、基建扩建
- 隐性成本：生态修复、住房补贴

**② 环境承载力子系统**：

碳排放约束：$CO_2(N_{tourists}) \leq CO_2^{max}$
冰川影响指数：$G = G_0 - k_g \cdot N_{tourists}$

**③ 社区满意度子系统**：
$$S = w_1 \cdot EconSat - w_2 \cdot CrowdIndex - w_3 \cdot HousingStress$$

### 2.2 系统动力学模型

采用系统动力学(SD)捕捉各子系统间的反馈回路：

- **正反馈环**：游客↑ → 收入↑ → 设施改善 → 吸引力↑ → 游客↑
- **负反馈环**：游客↑ → 环境↓ → 体验↓ → 游客↓
- **调控反馈**：游客↑ → 居民不满↑ → 政策干预 → 游客↓

### 2.3 数据来源

| 数据类型 | 来源 |
|---------|------|
| 财政收入 | 朱诺市FY21-FY23年度财务报告(CBJ ACFR) |
| 游客调查 | CBJ Cruise Passenger Survey 2021-2023 |
| 碳排放 | 邮轮公司环境报告 + EPA数据 |
| 住房成本 | CBJ Housing Report |
| 冰川数据 | USGS Mendenhall Glacier Monitoring |

## 三、求解与结果

### 3.1 关键参数

| 参数 | 基准值 | 来源 |
|------|--------|------|
| 邮轮游客/日 | 3,000-12,000 | 港口数据 |
| 人均消费 | $180 | 游客调查 |
| 碳排放/游客 | 17.5 kg/day | 邮轮报告 |
| 居民满意度 | 3.8/5 | 居民调查 |

### 3.2 优化策略

| 策略 | 具体措施 | 预期效果 |
|------|---------|---------|
| 旺季浮动税 | 旺季(5-9月)邮轮税+20% | 分流旺季游客 |
| 冰川预约制 | Mendenhall冰川单日限流2,000人 | 保护核心景点 |
| 生态修复基金 | 税收40%用于生态修复 | 改善环境 |
| 收入再分配 | 部分税收补贴居民住房 | 提升满意度 |

### 3.3 长期效果（10年模拟）

| 指标 | 优化前 | 优化后 | 变化 |
|------|--------|--------|------|
| 年财政收入 | $3,850万 | $4,160万 | +8.1% |
| 年碳排放 | 28,000吨 | 25,035吨 | -10.6% |
| 冰川退缩率 | 6.2m/年 | 4.8m/年 | -22.6% |
| 居民满意度 | 3.8/5 | 4.2/5 | +10.5% |

## 四、讨论

### 4.1 区域差异策略

| 区域 | 策略 |
|------|------|
| 市中心邮轮港口 | 旺季动态定价，淡季引流 |
| Mendenhall冰川 | 预约限流+接驳巴士 |
| 居民社区 | 旅游收入补贴住房 |
| 原住民文化区 | 文化遗产保护优先 |

### 4.2 模型稳健性

- 在±30%游客量波动下，碳排放始终在可控范围内
- 居民满意度对游客税率的敏感度最高（弹性系数0.65）

### 4.3 可推广性

该框架适用于全球生态敏感型旅游城市：威尼斯（入城税）、巴塞罗那（短租管控）、冰岛（景点限流）。
