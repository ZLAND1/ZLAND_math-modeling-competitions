| 项目 | 内容 |
|------|------|
| **时间** | 2024年11月15日 — 11月19日 |
| **选题** | D题：城市功能区位分析与规划 |
| **主办方** | 数维杯组委会（国际赛） |

---

## 一、题目概述

### 1.1 问题背景

城市功能区（商业区、居住区、工业区、绿地等）的空间分布直接关系到城市运行效率和居民生活质量。本题提供了某城市的POI（Point of Interest）数据和各类城市设施分布数据，要求分析城市功能区的分布规律并提出优化建议。

### 1.2 数据概况

数据包含17类城市设施/服务的空间分布（CSV格式经纬度坐标）：
- 住宿服务、商业-住宅、汽车服务、金融保险
- 餐饮服务、地名地址信息、政府与社会组织
- 室内设施、生活服务、医疗健康
- 摩托车服务、公共设施、零售服务
- 科教文化、交通设施
以及两个时间点的对比数据（Appendix 3 和 Appendix 4）

## 二、建模方法

### 2.1 空间分析方法

- **核密度估计(KDE)**：分析各类设施的聚集热点
- **空间自相关(Moran's I)**：检测功能区的空间聚集模式
- **缓冲区分析**：评估各类设施的服务覆盖范围

### 2.2 功能区识别

- 基于POI频数密度和类型比例，计算每个空间单元的功能主导度
- 采用TF-IDF思想：某类POI在某区域的密度高且在其他区域低，则该区域为相应功能区

### 2.3 区位优化

- 识别服务盲区（某类设施覆盖不足的区域）
- 基于人口密度和设施分布的供需匹配分析
- 提出新增设施的推荐位置

## 三、技术总结

### 3.1 城市数据科学

POI数据是城市研究的"新石油"——相比于传统的问卷调查和统计数据，POI具有实时性高、粒度细、覆盖广的优势。本次比赛的核心能力是将多源异构POI数据整合为统一的城市功能区画像。

### 3.2 城市规划思考

1. **15分钟生活圈**：本题实质上是检验城市是否实现了"15分钟生活圈"的规划理念——居民在步行15分钟内能否获取基本公共服务
2. **功能混合度**：过于单一的功能区（如纯居住区）会导致潮汐式交通，而适度的功能混合能提升城市韧性
3. **数据驱动的城市规划**正在取代经验导向的传统规划，但数据也有其盲区（如非正规经济、流动人口）
