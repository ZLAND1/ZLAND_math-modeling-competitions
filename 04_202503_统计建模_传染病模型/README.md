## 一、研究概述

### 1.1 研究背景

新发传染病的频繁暴发（COVID-19、猴痘、流感变异株等）对全球公共卫生体系构成持续挑战。本研究整合医疗大数据（疫情数据、气候数据、人口流动数据），构建传染病综合评估模型。

### 1.2 研究框架

**三大模型**：
1. **传染病分类模型**：基于临床特征的疾病快速分类
2. **传播动力学模型**：SEIR扩展模型，结合人口流动
3. **综合破坏力评估模型**：考虑传染性、致死率、经济影响的综合评价

---

## 二、建模方法

### 2.1 传播动力学（SEIR-VAQ模型）

在经典SEIR基础上扩展：
$$\frac{dS}{dt} = -\beta S I / N - vS$$
$$\frac{dE}{dt} = \beta S I / N - \sigma E$$
$$\frac{dI}{dt} = \sigma E - (\gamma + \mu) I$$
$$\frac{dR}{dt} = \gamma I + vS$$
$$\frac{dV}{dt} = vS$$

引入疫苗接种率v和人口流动因子λ（从省际流动数据估计）。

### 2.2 机器学习分类

使用多源数据（气候、人口密度、医疗资源）作为特征，训练分类模型区分不同传染病的传播模式。

### 2.3 破坏力综合评估

多维度指标体系：
- 流行病学维度：R₀（基本再生数）、病死率
- 经济维度：GDP损失、医疗资源占用
- 社会维度：隔离天数、公众恐慌指数

采用TOPSIS法综合评价各传染病的综合破坏力。

## 四、技术总结与思考

### 4.1 传染病建模的经典范式

1. **SEIR模型是流行病学的"牛顿定律"**：其简洁性和可扩展性使其百年来仍被广泛使用
2. **R₀不只是数字**：R₀>1意味着疫情扩散，R₀从1.5降到1.2需要约40%的人口免疫——数学揭示了公共卫生措施的杠杆效应
3. **气候-传染病的关联**：温度、湿度通过影响病毒存活时间和宿主行为间接影响传播

### 4.2 大数据在公共卫生中的应用

1. **流感预测的Google Trends**：搜索行为与疫情趋势的高度相关性已被多次验证
2. **手机信令数据**：在COVID-19期间被用于评估封城效果和密切接触者追踪
3. **医疗大数据整合**的瓶颈在于数据孤岛——不同医疗机构、不同地区的数据标准不统一

### 4.3 公共卫生政策思考

1. **疫苗犹豫(Vaccine Hesitancy)**：模型中的接种率v在现实中不是常数——社交媒体上的错误信息可能导致v大幅下降
2. **全球南方vs北方**：国际流动数据暴露了全球卫生治理的不对称——发达国家掌握更多数据和技术，但传染病的最大受害者往往在发展中国家
3. **One Health理念**：人类、动物、环境的健康是一体的——约75%的新发传染病是人畜共患病

### 4.4 比赛反思

统计建模大赛更加注重统计方法的严谨性和结果的可解释性。与数学建模竞赛"快速求解"的风格不同，统计建模需要更深入的假设检验、模型诊断和稳健性分析。
