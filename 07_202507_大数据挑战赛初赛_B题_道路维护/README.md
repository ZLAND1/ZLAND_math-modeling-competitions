## 一、题目概述

### 1.1 问题背景

城市道路网络是交通系统的骨架，科学的路面维护规划能大幅降低养护成本。本题提供84万条路段的路面状态数据，要求建立维护需求预测模型和优先级排序系统。

### 1.2 原始数据特征（10维）

| 特征 | 类型 | 说明 |
|------|------|------|
| Segment ID | 字符串 | 路段唯一标识 |
| PCI | 整数(0-100) | 路面状况指数 |
| Road Type | 分类 | Primary/Secondary/Tertiary |
| AADT | 连续 | 年平均日交通量 |
| Asphalt Type | 分类 | Concrete/Asphalt |
| Last Maintenance | 整数 | 上次大修年份 |
| AR | 连续(mm) | 年平均降雨量 |
| Rutting(R) | 连续(mm) | 车辙深度 |
| IRI | 连续(m/km) | 国际平整度指数 |
| NM | 二分类 | 维护需求标签(Label) |

## 二、建模流程

### 2.1 数据预处理

**特征工程**:
- 衍生特征 YSM = 2025 - Last Maintenance（维护间隔年数）
- 道路类型量化: Primary=3 > Secondary=2 > Tertiary=1
- 路面材料量化: Concrete=1 < Asphalt=2（沥青更易损坏）

**关键发现**（通过点二列相关和分箱分析）:
- Rutting与NM相关系数 **0.90**（极强）
- PCI与NM相关系数 **-0.85**（负相关）
- R > 17.03mm 时，NM=1准确率 **98.29%**（强规则）
- PCI < 35时，NM=1比例 97.6%

### 2.2 四个预测模型对比

| 模型 | 特点 | F1 Score |
|------|------|----------|
| 2阶多项式回归（Ridge, λ=10） | 引入x²和交互项，捕捉非线性 | 0.9985 |
| 带L2正则逻辑回归（λ=5） | 线性可解释，强正则防过拟合 | 0.9982 |
| 随机森林（深度8, min_split=50） | 限制复杂度防过拟合强规则 | **0.99996** |
| 带强正则XGBoost（γ=10, λ=5） | 强正则压制强规则依赖 | 0.9989 |

### 2.3 维护优先级排序

基于预测概率和特征加权构建**维护优先级指数(MPI)**：
$$MPI = w_1 \cdot P(NM=1) + w_2 \cdot f(R) + w_3 \cdot f(PCI) + w_4 \cdot f(AADT)$$

按MPI降序排列，生成优先维护路段列表。

## 四、技术总结与思考

### 4.1 强规则 vs 模型泛化

本题的核心张力：数据中存在极强规则（R>17mm → NM=1准确率98.29%），但模型需要泛化到"弱信号"路段（R在14-17mm之间的灰色区域）。

**策略**: 随机森林通过限制深度(min_samples_split=50)强制模型不完全依赖单特征强规则，在灰色区域学习了更细腻的决策边界。

### 4.2 道路工程知识

1. **PCI的科学性**：PCI不是单一测量值，而是通过ASTM D6433标准综合评估19种路面破损类型的加权得分——是一个浓缩了大量工程经验的特征
2. **车辙(Rutting)**：是路面结构层永久变形的累积，15mm是养护规范的临界值。数据中的17.03mm阈值与规范高度吻合——数据验证了工程理论
3. **降雨量(AR)**与路面损坏的正相关：水是沥青路面的"天敌"——水损坏导致沥青与骨料分离（剥落），加速路面老化

### 4.3 大数据竞赛的特殊性

与数学建模竞赛不同，大数据竞赛更看重：
- **特征工程**的质量而非模型复杂度
- **计算效率**：84万条数据需要考虑内存和训练时间
- **工程可落地性**：模型需要能部署到实际的养护管理系统中
