## 🛠 技术栈总览

### 数学建模方法
| 方法类别 | 具体技术 | 应用比赛 |
|---------|---------|---------|
| **优化方法** | 线性规划、混合整数规划、动态规划、多目标优化(NSGA-II)、L-BFGS-B | 01, 08, 10, 11 |
| **统计分析** | 方差分析、卡方检验、t检验、生存分析(Cox回归)、Spearman相关 | 04, 06 |
| **机器学习** | 随机森林、XGBoost、Stacking集成、CatBoost、K-means聚类 | 04, 06, 07, 08 |
| **时间序列/信号** | 三次样条插值、Savitzky-Golay滤波、交替优化、卡尔曼滤波 | 10, 11 |
| **物理建模** | Deutsch-Anderson方程、多体动力学、转动惯量计算 | 05, 11 |
| **综合评价** | TOPSIS、层次分析法、熵权法 | 04, 06 |
