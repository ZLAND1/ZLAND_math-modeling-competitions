## 一、题目概述

2022年国赛C题是经典的统计+机器学习题目：根据古代玻璃制品的化学成分数据（二氧化硅、氧化铅、氧化钾等14种成分），判断玻璃类型（高钾玻璃/铅钡玻璃），并分析风化对成分的影响。

### 核心问题
1. 分析表面风化与玻璃类型、纹饰、颜色的关系
2. 建立玻璃类型的分类模型
3. 预测风化前玻璃的化学成分
4. 分析各成分之间的关联关系

## 四、技术总结与思考

### 4.1 成分数据分析(Compositional Data Analysis)

玻璃成分数据的特殊性：各成分比例之和为100%，这违反了传统统计方法的独立性假设。CoDa方法通过log-ratio变换（如CLR、ILR）将Simplex空间映射到欧氏空间。

这一方法在多个领域有应用：
- 地质学（岩石矿物成分）
- 微生物组学（菌群相对丰度）
- 经济学（市场份额分析）

### 4.2 从"做题"到"研究"

研读优秀论文最大的收获是认识到：数学建模不仅是"解题"，更是"研究"——好的论文呈现出清晰的研究脉络：
1. 数据发现了什么？
2. 为什么用这个方法？
3. 结果说明了什么？
4. 对现实有什么启示？

### 4.3 考古学与统计学

本题的背景涉及古代丝绸之路的玻璃贸易——高钾玻璃源自中原技术体系，铅钡玻璃具有鲜明的地方特色（四川/湖南）。统计方法在此扮演了"数字考古"的角色，通过成分指纹追溯文化传播路径。这是数学建模最美妙的特质：用数字讲述人类故事。
